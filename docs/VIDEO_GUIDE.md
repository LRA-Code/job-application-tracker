# Recording your own 3–7 minute demo

The delivered recording demonstrates execution with fictional data. If you
need to demonstrate personally, use this roughly five-minute outline. Screen
record your browser, Flask terminal, and MySQL Workbench/terminal. Show real
operations; do not include passwords or `.env` contents.

| Time | What to show and explain |
|---|---|
| 0:00–0:30 | Start `python app.py`, show the server listening and open the dashboard. |
| 0:30–1:20 | Add a company, open its detail view, edit it, explain why it is a parent table. |
| 1:20–2:10 | Add a job tied to that company, add required skills, edit its salary/title. |
| 2:10–3:00 | Add an application, change its status, and save interview JSON. |
| 3:00–3:35 | Add, view, edit, and delete a contact. |
| 3:35–4:10 | Show skill matching: Python/SQL/Flask, 100% versus 67%, and missing skills. |
| 4:10–4:40 | Delete the application, job, and company with confirmation, in that order. |
| 4:40–5:10 | Show `SHOW TABLES`, a JOIN, JSON values, and Flask request logs. |
| 5:10–5:30 | Briefly explain AI assistance and where the setup instructions live. |

Save an MP4 under `video/`, then commit and push the actual file. Review playback
and ensure the final duration is between 3 and 7 minutes. A link to an external
video service alone does not meet the supplied requirement to upload a video
file to GitHub.
